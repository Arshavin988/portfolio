# Image Assets Documentation

This directory contains the production visual assets for Adebayo Elisha's academic portfolio website.

### Included Production Assets:
1. `elisha.webp`: High-resolution studio portrait of cybersecurity undergraduate Adebayo Elisha. Formatted in WebP (<90 KB) and rendered inside a custom organic SVG clip-path mask (`#organicCutoutMask`) on the homepage hero and about page.
2. `project_cybersecurity.webp`: Screenshot mockup for SOC Incident & Network Threat Analyzer.
3. `project_triangle.webp`: Architectural screenshot mockup for COS 102 Triangle Geometric Classifier.
4. `project_palindrome.webp`: Architectural screenshot mockup for COS 102 Palindrome Verification Engine.
5. `project_covid_analytics.webp`: Chalkboard wireframe sketch for COVID-19 Statistical Telemetry Pipeline.
6. `project_finance_thermo.webp`: Chalkboard wireframe sketch for Computational Finance & Temperature Converter.
7. `project_grade_analytics.webp`: Chalkboard wireframe sketch for University Grade Management Dashboard.

All project images adhere to a unified dark chalkboard wireframe aesthetic with white technical sketches for aesthetic cohesion.
